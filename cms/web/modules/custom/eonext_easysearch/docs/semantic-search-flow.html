FBI GraphQL API

Catalog source of truth — all display metadata

URL
dpl_fbi.settings / library profile
e.g. https://…/graphql
Auth
Bearer token (LibraryTokenHandler)
When called
Index: complexSearch (paginated) Search: works(id: […]) hydrate
Index operation
complexSearch(cql, filters) → works with title, creator, abstract, subjects, type, language, audience
Search operation
works(id: $ids) → full Work objects for React CardListItem

TEI — Text Embeddings Inference

Turns text into 384-dimensional vectors (local Docker)

URL
TEI_URL → default http://tei:80
Model
intfloat/multilingual-e5-small (384 floats)
When called
Index: embed passages Search: embed query Only if EONEXT_EASYSEARCH_EMBEDDING=tei
HTTP
POST /embed
Input
{ "inputs": ["passage: …", …] } or query: … — max 16 strings per request
Output
JSON array of float[384] vectors, same order as inputs

Qdrant

Vector database — stores embeddings + searchable payload

URL
QDRANT_URL → http://qdrant:6333 or Qdrant Cloud
Collection
fbi_materials — cosine distance, 384 dims (TEI mode)
When called
Index: PUT points (upsert) Search: POST points/search (kNN)
Point structure (TEI mode)
id: UUID from workId
vector: float[384]
payload: workId, title, creator, abstract, materialType, languageCodes, …
Search output
Ranked hits: workId + score + payload (used for filtering; display still from FBI)
Alt mode
qdrant_inference — Qdrant embeds text itself; TEI not used
Drupal orchestrates everything between these three. React never talks to FBI, TEI, or Qdrant directly — only to GET /api/v1/material-semantic-search on /easy-search.

Orange dashed = indexing · Green solid = live search · Blue dashed = TEI embed on search

Index steps
  1. Drush → Drupal starts batch
  2. Drupal → FBI complexSearch
  3. Drupal → TEI embed passages
  4. TEI → Qdrant upsert vectors
Search steps
  1. Browser → Drupal REST API
  2. Drupal → TEI embed query
  3. Drupal → Qdrant kNN search
  4. Qdrant → FBI works(id) hydrate
  5. FBI → Browser JSON results
FBI — catalog TEI — embeddings Qdrant — vectors Drupal — orchestration React — UI only
